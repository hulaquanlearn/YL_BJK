处理输入和输出，I/O - 安全信号

安全I/O 信号
 
概述

在控制器的基本和标准形式中，某些 I/O 信号专用于特定的安全功能。以下是简要描述。

所有信号可以在 FlexPendant 上的 I/O 菜单中查看。
