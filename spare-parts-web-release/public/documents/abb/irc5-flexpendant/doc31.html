Program Data（程序数据）
 
概述

Program Data（程序数据）视图包含用于查看和使用数据类型和实例的功能。您可以同时打开一个以上的 Program Data（程序数据）窗口，在查看多个实例或数据类型时，此功能非常有用。

Program Data（程序数据）图示

本节显示了Program Data（程序数据）视图的图示。

Change Scope（更改范围）

更改列表中数据类型范围，请参见查看特定任务、模块或例行程序中的数据。

Show Data（显示数据）

显示所选数据类型的实例。

View（查看）

显示所有或已使用的数据类型。

以下是数据类型实例列表。

过滤器

New（新建）

新建所选数据类型实例，请参见新建数据实例。

Edit（编辑）

编辑所选实例，请参见编辑数据实例。

Refresh（刷新）

刷新实例列表。

View Data Types（查看数据类型）
