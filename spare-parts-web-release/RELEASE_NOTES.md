# 原粮车间数字工作台更新说明

## V1.1.2 · 2026-08-31

- 修复原粮车间 3D 布局：1—14 号货架恢复左右对称分布，1、2 号货架不再重叠；15—20 号及未命名货架恢复原始坐标与尺寸。
- 前端物理布局常量、API 新建货架默认值和数据库迁移统一采用同一套现场坐标，避免只改 SQL 后又被页面覆盖。
- 新增安全增量迁移 `migration_raw_grain_shelf_spacing_20260831.sql`，只修复未人工拖拽的原粮系统货架，不修改库存、货位编码或人工位置。
- 部署包继续包含已重构的备件模型库：不在备件关联页平铺系统类别模型；支持搜索后批量上传专用 3D、批量关联类别模型；类别模型可独立搜索、新增、修改、替换和删除。
- 部署验收增加静态资源指纹核对，防止 Nginx 实际站点目录仍加载旧版模型库页面。

## V1.1.1 · 2026-08-31

- 恢复微信小程序首页的“新增备件”入口，不再只对总管理员显示。
- 总管理员可选择原粮、制曲或酿酒车间；车间账号自动锁定所属车间，不能越权新增。
- 新增请求明确提交 `workshopCode`，货区、货架和物料重复查询也按所选车间隔离。
- 制曲车间新增备件时不再强制选择货区，可选填具体存放位置。

## V1.1.0 · 2026-08-31

- 备件模型库重构为“备件模型关联”和“类别模型管理”两个独立工作区，移除页面中无操作意义的类别模型说明条。
- 搜索备件后支持批量选择，并可批量上传同一个专用 GLB/GLTF，或批量关联可复用的类别模型。
- 类别模型改为数据库正式资源，支持独立搜索、新增、上传、修改、替换和删除；全局类别资源仅总管理员可维护。
- 3D 库位按“备件专用模型 → 已关联类别模型 → 通用几何模型”取用，代码不再写死类别模型；删除类别模型后关联备件自动恢复通用模型。
- 选中备件卡片移除“已定位备件”冗余文案；网站页脚不再展示内部版本号。
- 延续 V1.0.1 的货位镜像定位、库存红绿着色、层筛选保持以及选中虚线清理。

## V1.0.1 · 2026-08-30

- 修正货架东西两侧的货位编号方向，西侧货位在 3D 坐标中镜像定位，模型落在对应层板和货位。
- “全部备件”模式直接按库存状态着色：正常为绿色，低库存为红色；不再叠加容易造成红绿混杂的状态环。
- 点击备件时保留当前层位筛选，不再自动恢复四层全选。
- 已展示模型时点击只增加定位箭头，不再重复叠加选中模型和白色边线，消除虚线与重影。

## V1.0.0 · 2026-08-30

- 3D 库位改为一个物理货位只生成一个备件模型，解决同货位串模和红绿状态混杂。
- 货架层位筛选后的右侧数量与列表同步，仅统计已选层。
- 新增轴承、断路器、阀门/电磁阀、传感器/开关四类 GLB 系统模型。
- 新建盘点任务的车间、盘点人和日期在桌面端同排展示；盘点范围不再截断为“全部...”。
- 台账导入新增文件内重复货位与现有货位占用校验；冲突行拒绝导入。
- 导入错误支持下载带“错误原因、修改建议”的完整修正台账，修改后可直接重新校验导入。

# 2026-08-24 工业程序智能分析升级

- 门户和业务界面统一更名为“智能工程中心”，移除品牌中的“制曲”字样。
- 新增 ABB RobotWare / RAPID 项目类型；网页可一次选择完整程序文件夹，递归导入 `.mod/.modx/.sys/.sysx/.cfg/.rapid`。
- RAPID 静态解析覆盖 MODULE、PROC、FUNC、TRAP、变量、条件分支、循环、运动指令、I/O 和例程调用。
- 程序列表直接显示程序含义；证据抽屉新增可展开逻辑树，并保留相对目录和源码行号。
- `.ap16/.ap17` 上传后进入 Windows 自动解析队列；V16/V17 节点按文件名和 SHA-256 定位本机完整项目，使用 TIA Openness 只读导出并回传原项目记录。
- 新增独立 `PLC_AGENT_TOKEN` 鉴权，解析节点不使用用户登录令牌，不需要开放 Windows 入站端口。
- 无人值守 TIA 解析不尝试密码；加密块仍需用户在本机交互解析器中自愿解锁。
- 数据库增量迁移：`server/sql/migration_program_analysis_20260824.sql`，不含 DROP/TRUNCATE/DELETE。
- 验证：服务端测试 17/17、网页测试 13/13、Vue 生产构建通过、V17 解析器 0 错误编译。
