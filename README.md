## 账号与板块

- 所有用户使用同一套账号登录，登录后进入业务板块门户；网页只保留账号菜单与安全退出，管理员可通过 Windows 独立账号管理器或小程序账号页维护账号。
- `admin` 可修改全部车间；`raw_grain`、`qu_making`、`brewing` 可查看全部车间但只能修改所属车间；`viewer` 为车间人员（只读），可查看全部车间及现有功能入口，新增、编辑、删除、导入、出入库、关联和审批等按钮仍展示；点击提示“权限不足”，请求层与后端同时禁止业务写入。
- 新建、修改、重置及初始化管理员密码不设长度限制，但必须同时包含大写字母、小写字母和数字，特殊符号可选。原有密码继续有效，不因规则调整强制重置。
- 备件列表支持原粮、制曲、酿酒三车间筛选和跨库搜索，并可跳转到对应车间的 3D 库位。
- 备件一览直接提供“详情、3D定位、出入库”，编辑、删除集中在详情页；勾选后可预检并批量删除（每次最多200条）：编辑不会直接改库存或覆盖历史流水；删除采用逻辑停用，库存不为0、存在待审批盘点或仍关联设备型号时会明确拒绝。
- Excel 台账导入采用整批预检；文件内重复货位或已被其他物料占用的货位会拒绝导入，并可下载完整错误修正台账后直接修改重试。
- 3D 库位按现场平面图固定为画面上方为东：1—14号中间成对紧邻，15—20号左侧单列并与双列保留通道，上端为三组未命名货架；库房大小不允许在页面人工调整。3D实体货架统一蓝色，铭牌按工段着色，2D货架沿用铭牌颜色；2D入口位于左侧，不提供货架新增、编辑或拖拽入口。一个物理货位只显示一个模型，正常库存为绿色，低库存为红色；模型按每侧每层的货位宽度、深度及层间高度等比适配并贴合层板，缩放倍数不能突破货位上限。
- V1.3.2包含用户七张参考照片及七类自包含GLB示意模型。`server/scripts/associate-reference-models.js` 默认仅生成匹配计划，显式确认后才更新类别关联并补充空图片；类别名称由管理员修改后仍按稳定资源路径识别，重复部署不会恢复旧名称。保留历史专用模型字段和文件供回滚；当前展示使用类别模型，人工类别和图片不动，不修改库存。参考模型不代表精确型号或制造尺寸。
- 3D模型仅接收自包含GLB 2.0文件（最大50MB），服务端校验文件头、版本和完整长度；GLTF需先连同BIN与贴图导出为GLB。
- 模型库分为"备件模型关联"和"类别模型管理"：支持搜索后批量关联类别模型；专用模型入口与写入接口停用；总管理员可维护类别模型的名称、关键词、文件和缩放。
- 当前源码资源为 51 个类别 GLB 及 51 张 JPG，另有 7 个参考 GLB 及 7 张 PNG；资源位于 `spare-parts-web-release/public/models/`，打包后位于 `web-dist/models/`。新增类别包括三角带、筛网、畚斗、止逆器、托辊、橡胶弹簧和万向轮。类别模型采用 Three.js 几何体与 GLTFExporter 生成，仅作形状示意；文件齐全不等于线上备件均已关联，旧版 94% 或 97% 的估计不作为覆盖结论。
- “设备与备件”按设备型号维护关系，不要求逐台填写设备编码；批量导入只强制设备型号，物料编码可选，失败时可下载带原因和建议的修正台账。
- 工程知识按车间归属；总管理员可删除全部知识，其他可编辑账号只能删除自己创建或上传的知识，其余知识只读。

## 权限与数据保护（沿用 V1.7.0）

- 网页及小程序：车间人员可看到各功能入口和操作按钮；尝试新增、编辑、删除、导入、出入库、关联、盘点、审批、修改配置或管理账号时，统一提示权限不足。查询、详情、历史、下载、模型预览和定位二维码保持可用。管理员原有编辑范围继续生效。
- 小程序的审批页和账号管理页可供车间人员查看，账号列表只返回编号、账号名、显示名、角色和启停状态；新增、启停、改角色、重置他人密码由服务端再次拦截。本人登录、退出和修改密码不受业务只读限制。
- /api/ 业务数据必须使用有效 Bearer 会话；上传图片、模型及包内 /models/ 参考照片均须鉴权。浏览器资源使用 HttpOnly、SameSite=Strict 的目录专用会话 Cookie，生产环境仅 HTTPS；Cookie 只用于读取资源，不能授权业务接口。账号停用、会话过期或撤销后资源也不可读取。
- 业务响应和模型资源设置 private/no-store；网页限制站外资源和连接、禁止嵌入外站、禁止索引，并拒绝意外放进静态目录的配置、备份、SQL、源码映射等文件。robots.txt 只作搜索引擎声明，实际保护依靠鉴权和访问控制。
