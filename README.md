## 权限与数据保护（沿用 V1.7.0）

- 网页及小程序：车间人员可看到各功能入口和操作按钮；尝试新增、编辑、删除、导入、出入库、关联、盘点、审批、修改配置或管理账号时，统一提示权限不足。查询、详情、历史、下载、模型预览和定位二维码保持可用。管理员原有编辑范围继续生效。
- 小程序的审批页和账号管理页可供车间人员查看，账号列表只返回编号、账号名、显示名、角色和启停状态；新增、启停、改角色、重置他人密码由服务端再次拦截。本人登录、退出和修改密码不受业务只读限制。
- /api/ 业务数据必须使用有效 Bearer 会话；上传图片、模型及包内 /models/ 参考照片均须鉴权。浏览器资源使用 HttpOnly、SameSite=Strict 的目录专用会话 Cookie，生产环境仅 HTTPS；Cookie 只用于读取资源，不能授权业务接口。账号停用、会话过期或撤销后资源也不可读取。
- 业务响应和模型资源设置 private/no-store；网页限制站外资源和连接、禁止嵌入外站、禁止索引，并拒绝意外放进静态目录的配置、备份、SQL、源码映射等文件。robots.txt 只作搜索引擎声明，实际保护依靠鉴权和访问控制。
- 按来源 IP、账号每分钟/每小时、资源及附件下载分别限流，超限返回 429 和等待时间；异常记录不包含令牌、密码、查询参数或业务正文。当前内存计数按单个 API 进程生效；多进程/多实例须增加共享限流存储或统一网关策略，重启会清空计数。
- 默认禁止业务内容传往 AI 网关，包括可能转发到云服务的本机网关。站内检索仍可用；不声称检索结果由 AI 生成。
