- 按来源 IP、账号每分钟/每小时、资源及附件下载分别限流，超限返回 429 和等待时间；异常记录不包含令牌、密码、查询参数或业务正文。当前内存计数按单个 API 进程生效；多进程/多实例须增加共享限流存储或统一网关策略，重启会清空计数。
