# 数字工作台

当前正式版本：**V1.1.2**（2026-08-31）

版本采用语义化规则 `V主版本.次版本.修订号`：兼容性修复提升修订号，向后兼容的新功能提升次版本号，存在不兼容变化时提升主版本号。每次正式发布同步更新 `VERSION`、前后端 `package.json`、更新说明、部署说明和校验文件。

项目采用“统一账号 + 业务板块门户”，包含备件管理中心和智能工程中心。微信小程序使用“自建 API + MySQL”，网页端登录后按板块进入对应业务；账号创建、删除、密码重置和角色分配统一由独立账号管理器完成。

## 目录

- `miniprogram/`：微信小程序正式代码与图片资源。
- `server/`：Node.js/MySQL API、工程知识附件、TIA/ABB程序解析与只读AI分析服务、迁移脚本和测试。
- `spare-parts-web-release/`：Vue网页端源码，包含板块门户、备件管理和智能工程；发布前必须重新构建 `dist/`。
- `output/`：最终部署包、校验文件、OpenClaw 部署说明和测试报告。
- `tools/tia-openness-exporter/`：TIA Portal V16/V17 本机解析助手源码与构建脚本。
- `project.config.json`：微信开发者工具项目配置。

旧 CloudBase 云函数、云开发规则、编辑器配置、根目录 npm 测试工程及临时网页构建目录均已移除。当前版本使用自建账号登录和“只读/车间/总管理员”分级权限。

## 账号与板块

- 所有用户使用同一套账号登录，登录后进入业务板块门户；网页只保留账号菜单与安全退出，账号管理集中在 Windows 独立账号管理器。
- `admin` 可修改全部车间；`raw_grain`、`qu_making`、`brewing` 可查看全部车间但只能修改所属车间；`viewer` 只读。
- 备件列表支持原粮、制曲、酿酒三车间筛选和跨库搜索，并可跳转到对应车间的 3D 库位。
- Excel 台账导入采用整批预检；文件内重复货位或已被其他物料占用的货位会拒绝导入，并可下载完整错误修正台账后直接修改重试。
- 3D 库位坚持一个物理货位只显示一个模型；东西两侧的货位号按各自观察方向镜像定位。正常库存模型统一为绿色，低库存统一为红色。
- 模型库分为“备件模型关联”和“类别模型管理”：支持搜索后批量上传专用模型、批量关联类别模型；总管理员可维护类别模型的名称、关键词、文件和缩放。
- 工程知识按车间归属；车间角色只能上传和维护本车间资料，总管理员可物理删除知识记录及服务器附件。
- 工程知识附件保存在服务器持久化目录，不放入网页公开目录，下载必须携带登录令牌。
- PLC程序文件同样保存在服务器持久化目录；网站只分析导入的离线副本，不连接在线PLC。

## 工业程序智能分析

“智能工程中心 → 程序智能分析”支持 Siemens TIA V16/V17 和 ABB RAPID。网页上传 `.ap16/.ap17` 后，由对应版本的 Windows 解析节点在本机定位完整项目、只读导出并自动回传；ABB 支持一次选择整个 RAPID 文件夹，递归解析 `.mod/.modx/.sys/.sysx/.cfg/.pgf/.rapid` 并生成逻辑树与程序含义。

Know-how加密块由本机解析助手逐块询问是否输入密码。密码只以 `SecureString` 存在于本机进程内存，不上传、不保存、不记录日志；网站不提供密码输入框。系统不具备连接、下载、强制、启停或写入PLC的能力。

## 小程序

所有环境统一使用 `https://czsdsg.cn/api`。网站备案和公安备案已完成；微信公众平台仍需保留 `https://czsdsg.cn` 为 request 合法域名。

小程序“新增备件”按车间权限开放：总管理员可选任意车间，原粮/制曲/酿酒账号只能向所属车间新增，只读账号不显示入口。制曲车间不强制货区，可选填具体存放位置。

