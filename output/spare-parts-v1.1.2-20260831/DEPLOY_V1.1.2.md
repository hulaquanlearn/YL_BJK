# 数字工作台 V1.1.2 部署说明

## 发布边界

- 版本：`V1.1.2`，日期：2026-08-31。
- 本包是完整增量包，已包含 V1.1.0、V1.1.1 的全部修改；服务器只需部署 V1.1.2，不要再单独执行旧版本。
- 本说明只提供人工发布步骤，不授权自动发布服务器或小程序。
- PLC 解析助手和独立账号管理器本轮未修改。

## 部署前

1. 备份 MySQL 数据库、工程知识附件目录和现有服务器程序。
2. 记录 Nginx 中 `czsdsg.cn` 实际使用的 `root` 或静态站点目录，不能仅凭项目目录猜测。
3. 不得清空或覆盖 `parts`、`inventory`、`categories` 等业务数据表，不得删除知识附件和程序归档目录。

## 服务器与网页

1. 用包内 `server/` 替换应用程序代码，保留生产 `.env` 和持久化上传目录。
2. 在 `server/` 执行 `npm ci --omit=dev`，再按现有 PM2 配置重启 API。
3. 先备份数据库，再执行一次：

   ```sql
   SOURCE server/sql/migration_raw_grain_shelf_spacing_20260831.sql;
   ```

   该迁移仅修正 `raw_grain` 且 `position_overridden=0` 的系统货架，不覆盖人工拖拽位置。
4. 将包内 `web-dist/` 的全部内容完整替换到 Nginx 实际站点目录；不要只复制到未被 Nginx 使用的历史目录。
5. 重载 Nginx 后，查看线上 HTML 引用的 `assets/index-*.js`，必须与本包 `web-dist/index.html` 一致；不一致即说明仍在服务旧目录。

## 小程序

V1.1.2 包含 V1.1.1 已恢复的“新增备件”入口。如需发布小程序，用微信开发者工具导入包内 `project.config.json`，源码目录为 `miniprogram/`，由有权限人员手工上传审核。

## 必验项目

- 备件模型库不再显示截图中的四张“系统类别模型”平铺卡片。
- “备件模型关联”中搜索并勾选备件后，出现“批量上传专用3D”和“批量关联类别”操作。
- “类别模型管理”可独立搜索、新增、修改、替换和删除类别模型。
- 原粮 1、2 号货架左右对称、不重叠；人工拖拽过的货架位置保持不变。
- 总管理员可查看全部车间，车间账号只能修改权限范围内的数据。
- 小程序总管理员及车间账号可见“新增备件”，只读账号不可见。

## 回滚

如需回滚程序，恢复部署前 API 和静态站点备份。货架迁移没有删除业务数据；如确需恢复迁移前货架坐标，应从部署前数据库备份中只回写对应 `warehouse_shelves` 坐标字段，不要恢复整库覆盖新增业务数据。
