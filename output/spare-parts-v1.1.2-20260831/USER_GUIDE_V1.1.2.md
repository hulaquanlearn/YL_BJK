# 数字工作台 V1.1.2 使用说明

## 备件模型关联

1. 进入“备件模型库”，默认打开“备件模型关联”。
2. 按车间、编码、名称、规格或类别搜索备件。
3. 勾选一个或多个有修改权限的备件；只读或跨车间备件不能勾选。
4. 可选择：
   - “批量上传专用3D”：把同一个 GLB/GLTF 专用模型绑定到所选备件；
   - “批量关联类别”：把所选备件关联到一个可复用类别模型；
   - “清除类别关联”：恢复为通用模型。

3D 库位按“专用模型 → 类别模型 → 通用模型”的顺序显示；同一物理货位只生成一个模型。正常库存为绿色，低于安全库存为红色。

## 类别模型管理

切换到“类别模型管理”后，可搜索和查看类别模型。总管理员可以新增、上传、修改、替换、删除类别模型；删除后，原关联备件自动回退到通用模型，不删除备件台账。

## 原粮货架

V1.1.2 恢复原粮现场货架排列：1—14号左右对称，15—20号位于左侧单列。若管理员曾在3D页面人工拖拽某个货架，本次迁移会保留该人工位置。

## 小程序新增备件

- 总管理员可选择目标车间。
- 原粮、制曲、酿酒账号只能向所属车间新增。
- 制曲车间不强制货区，可填写具体存放位置。
- 只读账号不显示新增入口。
