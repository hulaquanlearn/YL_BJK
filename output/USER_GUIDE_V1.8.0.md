# V1.8.0 使用说明

本次增加5款有厂家尺寸依据的参考模型：明纬NDR-240-24、NDR-480-24及SKF 6006-2Z、6003-2RSH、61802。品牌和完整型号符合时，3D仓库使用轻量版；库存详情点击“查看3D模型”加载精细版，收起后释放预览。尺寸参考不等于制造级CAD，近似范围和厂家资料入口在预览中说明。

其余537条仍待资料核对和建模。名称含禁止使用、替代、附件或不符型号后缀的物料不会套用这些模型。既有数据库关联不自动改写。


首页采用浅色工作台，两个业务区提供主入口和常用功能快捷入口，手机单列展示。库存明细默认按名称、物料编码、规格型号、货区/库位、当前库存、订购点、库存状态排列；所属车间、备件类型可在自定义列中开启。库存概况进入页面即展开，点击标题可收起或重新展开。

3D库位的展示方式切换与刷新现位于模型标题栏，刷新使用图标，悬停显示“刷新布局”；手机自动换行。

## 账号权限

| 角色 | 查看 | 修改 |
| --- | --- | --- |
| 系统管理员 admin | 所有车间 | 所有车间及系统配置 |
| 车间管理员 raw_grain / qu_making / brewing | 所有车间 | 仅所属车间；跨车间共用物料的全局图片和类别资源由系统管理员维护 |
| 车间人员 viewer | 所有车间 | 入口和按钮可见，点击业务写操作提示权限不足，不能新增、编辑、删除、导入、出入库或审批 |

车间人员可进入审批页和账号管理页查看；账号只显示基本信息，点击新增、修改、启停或重置他人密码时提示权限不足。本人修改密码仍可使用。

账号仍由管理员创建。人员可以查看知识、下载资料和提出业务问答；问答仅查询资料，不修改业务数据。小程序账号管理页提供完整角色名称，新增账号默认只读。

新建账号、修改密码、管理员重置密码和初始化管理员统一要求：密码为 6 至 72 位，同时包含大写字母、小写字母和数字，特殊符号可选。原有密码继续用于登录，不会因规则调整被强制重置。

## 本轮操作变化

- 库存搜索在最前面，统计点击“库存概况”展开；手机库存列表使用卡片，可直接查看数量、位置和操作。其他宽表格继续支持左右滑动。
- 模型关联列表每页24项，翻页保留已选；“全选筛选结果”作用于全部匹配物料。类别卡片显示名称、图片和关联数量，配置项在编辑器中维护。
- 知识列表不再显示常规处理进度，详情仍可查看；处理失败仍在列表提示。
- 小程序常用功能前置，低库存直达列表；加载失败可重试且保留旧结果；选好盘点范围直接进入列表，最终提交审批的确认仍保留。
- “库位说明”是静态帮助图，不代表小程序具有网页实时3D功能。

## 库存与统计

“全选筛选结果”选择当前筛选条件下所有页中可操作的备件，表头勾选框选择本页。“取消选择”清空；翻页保留；变更筛选并查询会清空。已选数量、批量出入库、批量删除与新增、导入、自定义列处于同一工具栏，窄屏会换行。

批量删除沿用单次最多 200 条及零库存、无待审批盘点、无设备关联等校验。全选不绕过这些条件。批量操作提交前核对明细。

统计“车间 / 货区 · 类型明细”支持点击表头升序、降序和取消排序。库存数量按单位及该单位数量比较，不将不同单位相加。

盘点期间如果账面库存发生变化，提交会提示刷新重盘；审批时仍会再次验证库存快照，避免覆盖新发生的出入库。

## 3D 库位与类别模型

默认“全部备件”，下拉可切换“正常库存”“低库存”“隐藏备件”。低库存按已配置订购点且库存不大于订购点判断；正常库存按已配置订购点且库存大于订购点判断，未配置的备件在“全部”中查看。隐藏只清空备件展示，保留货架和定位功能。

3D 工具栏移除重复的“备件模型库”按钮。全局导航仍可进入模型库，维护类别模型与物料关联。专用模型筛选、上传和缩放入口已撤下；类别模型及参考图继续使用。未关联或模型加载失败时显示通用示意，不能据此认定准确模型已覆盖。

进入页面默认收起右侧货架列表，整体视角适当拉近；可用“显示列表 / 收起列表”切换。点击货架或搜索定位备件时会展开对应明细。四张统计卡、画布右上入口提示和底部操作提示已移除；操作说明统一放在库房名称下方。库房内的入口标记和方向标记保留。

## 知识库

左侧按“全部知识 / 资料文档 / 故障知识”和资料分类浏览，右侧搜索并选择车间，列表可切换卡片。选择条目打开详情，可在线阅读或下载附件。

右上“知识问答”打开问答侧栏，回答附检索证据，点击证据查看来源。默认开启数据保护，仅给出站内检索结果，并明确提示未经 AI 生成，不向模型网关发送业务内容。管理员可新增知识、配置工序和标签；有权限的作者可修订、替换附件和查看历史。

新增与编辑窗口采用宽版左右布局：左侧基本信息，右侧文档摘要、附件或故障内容。上传区缩短，取消和提交按钮固定在底部；小屏自动改为单列，只滚动窗口内的表单。

## 手机网页查看

手机与电脑使用同一网址和账号。导航可左右滑动；筛选和按钮自动换行，宽表格在表格内左右滑动，手机不固定左右两侧列，避免遮挡内容。弹窗限制在屏幕内，详情侧栏在手机上占满宽度。

3D 页面按竖屏比例取景，默认收起货架列表。触摸操作为单指旋转、双指缩放和平移，点击货架查看明细，点“复位视角”恢复全景；也可切换 2D 平面查看。手机采用较低的像素比和阴影分辨率以降低绘制负担，实际流畅度仍需在使用的手机上验收。

## 模型搜索与关键词关联

1. 在“备件模型关联”搜索物料；点击“按关键词匹配”核对当前搜索结果。已有人工关联自动保留。
2. 可直接关联项目默认勾选；“需要核对”中先查看 3D、判断实际形状，再选择候选。没有合适模型时保持未选，不强行绑定。
3. “未匹配”需补充合适类别或匹配词；“资源缺失”需先修复模型文件。词命中只提供候选，不代表精确型号相同。
4. 点击“关联所选”提交，超过 500 条自动分批；遇到并发修改会显示已完成数，刷新重新匹配后继续。车间管理员仍仅可修改本车间独占物料，共用物料由系统管理员处理。
5. 保存类别关键词不会自动改变现有物料。再次进入匹配预览，核对后提交。也可沿用勾选物料、手动选择类别并批量关联的操作。

类别下拉支持中文、关键词、完整拼音和拼音首字母，例如输入“消声”“xiaosheng”或“xsq”。中文按拼音、英文按字母统一 A–Z 排列。类别管理的搜索不会删减关联下拉中的选项。

3D 定位卡片按名称、物料编码和四格库位展示；规格已包含在名称中时不重复显示。定位二维码仍可打开。不再单独显示“未绑定3D模型 · 当前为通用示意”说明；实际是否关联请到模型库查看。

## 登录资源与访问限制

业务数据、上传图片、模型和参考照片均需有效登录，链接不会作为公开下载地址。查看被拒绝时先检查登录是否过期；若提示访问过于频繁，请等待后重试。不要分享账号、会话令牌或下载的业务资料。资源专用Cookie仅用于浏览器图片和3D加载，不赋予修改权限。
