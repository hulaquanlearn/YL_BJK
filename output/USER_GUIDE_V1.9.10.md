## 本轮使用变化

- 后续简化：备份列表靠左，刷新/导入/导出靠右，不再搜索；每张备份的“编辑”可重命名或确认删除，操作未选中备份不会切换当前源码。源码始终展开，不再提供代码折叠。
- 文件导航加宽，名称完整换行。阅读区下方“展开”加宽源码，点“收起”恢复；不折叠或隐藏代码。查看例程或不可读文件时也可收起返回原布局。
- 2026-10-20：桌面备份栏一行排列，不可读文件在导航末尾。“继续生成”依次处理全部未完成批次，单批失败自动跳过并在明细保留原因；结束后可再次继续重试。点“本批完成后暂停”保留当前批次结果后停止。运行时请保留当前页面；刷新/离开后可继续已保存的进度。累计2000条不再阻断生成，记录仍有32MB保护上限。
- Android独立新版android.5：在“我的→检查App更新”升级；登录页可勾选“记住密码（仅此手机）”。成功登录后加密保存，下次自动填写，仍需点击登录。已登录用户可先退出再首次保存；取消勾选或“我的/更多→密码保存设置”可清除。既有完整部署包仍附android.4。
- 机器人源码采用编辑器式阅读，蓝色关键字、绿色注释、固定行号和代码折叠；默认保留缩进与长行，支持自动换行和展开阅读。智能体显示真实任务计数，明细可展开，新对话在输入框旁。
- 考勤只展示当前导入，不保留历史记录；新文件成功导入后替换上一份及其备注，失败保留当前有效结果。

- 网页和App共用功能/账号权限；小程序保持原功能/权限。
- 知识问答按轮显示自己的问题、回答和资料引用，可连续追问；当前浏览器会话支持刷新恢复。切换账号或文件版本隔离上下文，点“新对话”清空本次上下文。
- 机器人问答保留历史，“新对话”不删除已生成注释。分批引用按实际提供的源码验证；不可读模块不猜测。
- 3D加载提示跟随真实阶段和完成数量；失败有提示和重试，不用等待虚假百分比。
- Android首次安装 app-updates/android/ 内正式APK；后续在“我的/更多→检查App更新”下载安装，经系统确认覆盖。旧debug体验版与正式签名不同；正式同签名升级保留应用数据。业务网页随服务器更新，不必重装App。

## 入口

工作台主按钮进入相应中心，下方是具体功能直达。智能工程按 ABB程序智能分析、工程知识库排序；工作中心下方是工段长履职考评、考勤核查。右上角头像进个人中心，业务导航不重复放调用记录/资料管理。

低频维护在对象旁“更多”，新增靠列表、设置靠分类，筛选有条件才显示重置。手机自适应，3D 会先准备当前完整模型再显示。

## ABB程序智能分析

系统管理员在工具栏导入 ABB ZIP（不超过 20 MiB），默认自动中文注释；失败可继续未完成批次。刷新/切换/登录读取保存结果，不重新调用模型。导出中文注释阅读包，原备份不改写。

卡片 × 删除需确认当前版本，分析中或版本变化拒绝；内容移入服务器私有 .deleted 归档并写删除标记，旧浏览器不会自动复活，不清空次数。

对话统一“发送”，支持解释、提问和修改建议；建议校验原文/行号，审阅确认后加入导出建议稿，不自动写回备份/控制器。不可读模块不解密猜测；结果需设备现场复核。

系统管理员不限，车间管理员每账号每日最多 3 次；整份分批注释 1 次，单次提问/修改各 1 次，继续原任务不重复、正常失败不扣，北京时间零点重置。其他获授权人员只看已有结果；导入、删除、重命名和连接维护仅系统管理员，原粮员工不能访问。

## 工程知识问 AI

搜索栏“问 AI”面向知识库；资料详情或在线阅读的“问 AI”关联当前文件，弹窗显示名称。服务端读取正文/版本，优先当前文件，再检索相关故障、设备和备件，回答附可点击出处，切换文件清空旧对话。

无提取正文时明确提示处理索引，不冒充已阅读；删除/版本变化需刷新。长文仅选问题相关片段，不能据文字问答宣称完整理解扫描电路图或未提供的接线参数。

管理员不限；车间管理员每账号每日成功最多 3 次，网页/小程序/安卓共享，北京时间零点重置，独立于 ABB/原粮总结。失败、无正文、检索降级/无关问题不扣；其他人员不可调用模型。小程序纯库存自然语言查询保留。当前通道直连 DeepSeek，无需新建 OpenClaw agent。

## 个人中心

本人可维护姓名/密码，角色/车间/岗位按原权限只读。仅系统管理员增加以下页签，前后端同时限制：

- API 与 Codex 用量：DeepSeek API 余额、GLM 普通 API 余额、混元个人 Hy Token Plan 积分、本机 Codex 或配置的脱敏快照；口径各异不混算，不可用如实显示，平台总余额不等于本站消费。生产不会自动继承本机凭据/登录。
- 调用记录：全员时间/账号、来源、功能、模型、结果、耗时与已知 Token；按日期/来源/功能/结果筛选，无账号搜索。来源为网页/微信小程序/安卓 App，历史缺标记显示“—”而非猜测；安卓新标识需另建 APK。
- 账号管理：新增、身份/岗位编辑、启停、重置密码，低频操作在更多。本账号不能停用自身/取消自身管理员；变更他人身份/密码按原规则撤销会话。
- 资料管理：一个列表筛选全部/考勤/履职照片，按日期预览批量清理或单项删除。管理员可删除历史和关联照片，确认后永久移除图片并解除引用，保留文字、提交状态和审计；不自动删除真实资料。版本变化/缺失整批失败，刷新再选。逻辑释放不代表 MySQL 磁盘立即缩小。

调用审计不保存密钥、问题/回答全文。额度、审计及真实机器人库保留在私有目录，不当临时文件清空。

## 保留业务与权限

库存/补货、盘点、出入库、设备关系、名称模型绑定、3D、工段长履职与考勤按现有权限使用。原粮岗位为车间管理员、工段长、员工；旧 group_leader 按员工限制，现场逐个核对再规范保存，不自动提升。员工仅备件查询/详情/库位及本人维护。

履职提交/审核状态本轮按用户要求保留现状，没有改为新的“填完/未填完”流程。考勤沿用规则 7，保留原件、备注/导出，结果仍需人工核查。
