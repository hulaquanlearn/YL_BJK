# Reliable V4（Dify 1.14.2）

## 导入配置

1. 导入 `spare-parts-reliable-v4-dify-1.14.2.yml`。
2. “检索备件知识库”节点默认不携带任何知识库 ID；只绑定内网最新知识库，确认节点里只有一个知识库。
3. 知识库必须使用经济型索引，并将检索方式设置为关键词检索，不能使用语义检索。
4. “备件智能分析”节点选择内网聊天模型。
5. 保存后新开预览会话测试 `502000268`、`502000575` 和“有多少种易损件”。

## 关键修复

- 精确编码只用编码检索。
- 清除了 DSL 中残留的旧知识库 ID。
- OpenClaw 生成的每条库存分段必须重复物料编码 10 次，确保 Dify 经济型索引的前 10 个关键词中包含物料编码。
