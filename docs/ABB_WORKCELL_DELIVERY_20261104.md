## 本批内容

- 主模型保留一个程序运行会话。面板隐藏或打开示教器不会卸载执行器；示教器复用实时关节、当前源码行和状态，不再挂重复运行面板。实体程序键对接同一会话，运行期间阻止手动点动抢占。
- 主面板按备份/例程、运行键、装填参数、速度/倍速、详细信息排列；去掉“ABB · 主视图”，程序状态移到底部中间。运行面板由 DSH 提供 CSS，Codex 整合模板与逻辑；DSH 最终 CSS 哈希及未做 UI 核验的边界见 `ABB_PROGRAM_PANEL_DSH_20261104.md`。
- 顶栏精简为工具选择、场景设置、设备动作、程序运行；场景/设备使用与工具相近的按钮样式，不写文字箭头。底部保留默认受限旋转，另有 360°查看；全屏在最右。设备动作增加独立链板行走，链板在暂存斗远离机器人的一侧。
- 暂存斗底部改为有厚度的弧形挡料板，轴臂和气缸按几何端点联动。布料头护罩、气缸和打散轴随程序输出协调动作。接料定位的运动许可变化不再误触发程序停止而打断自身。
- ABB SMB 电池仓和 1–6 轴抱闸按钮独立标记，仓盖标记跟随回转座。
- 全流程从源 main 的调用链执行；所选 PROC 可单独运行。补齐 CTime/时钟、嵌套 RelTool/Offs 开关、角度单位、记录值拷贝、可写 speeddata、INOUT、FUNC ELSE、Stop/EXIT 与等待等解释问题。主程序的“2 条直接运动”不表示调用链只有两步。
- 运动、等待、气缸和链板/物料演示统一应用速度覆盖与 1/5/10/20× 演示倍率，默认 1×。未知功能仍阻塞，不对所有未知函数一概跳过。
- 工位模型把链板供料、暂存斗接料、机器人斗内余料和入甑体积串联。喂料下落流必须同时满足接料状态、实际接料姿态、暂存斗挡板开到位；上甑时使用打散轴出口的独立料流。没有铺出体积就不抬高料面。最后一斗按目标剩余量模拟给料。
- 斗容默认是内腔近似估算（640 约 90 L、700 约 100 L），允许 10–250 L 调整，不是 CAD 精确闭合容积或现场标定值。甑内高度按源标定下/上半径 1.09/1.20 m、内高 0.97 m 的锥台积分反算；物料外观采用土棕/米褐颗粒示意，尚未完成古井现场照片的精确视觉校色。
- ABB 产品手册弹窗不再被通用 PDF 弹窗的 flex 布局挤到左侧。PDF 打开默认整页自适应，去掉尺寸下拉框；直接滚轮/双指缩放、拖动查看，保留页码/翻页与“适应页面”复位。最大渲染像素数受限，避免手机放大时创建过大画布。单页翻阅方案，未实现 834 页同时连续渲染。
