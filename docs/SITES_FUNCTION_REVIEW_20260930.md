# 网页功能核对与 Sites 界面改善

日期：2026-09-30。本地源码改动，未打包、未部署。

本次先核对实际路由、页面模板、调用接口、权限和此前确认的流程，再改善展示。没有迁移框架、引入第二套组件库或更改业务数据库。

## 功能与界面对应

| 页面 | 当前实际用途 | 界面处理 |
| --- | --- | --- |
| 数字工作台 | 三个业务中心及常用入口 | 保留备件、工程、工作顺序及各自主题色 |
| 库存总览 | 筛选、库存指标、跨页选择、详情、导入导出、批量操作 | 红色操作主题，筛选和库存表保持主次；手机指标两列 |
| 补货清单 | 低库存及最高储备差额、按单位统计、清单导出 | 保留补货专用筛选和目标缺失状态，不与流水混用 |
| 库存流水 | 类型、原因、时间筛选及操作追溯 | 保留流水字段和来源信息；与 3D 的定位控件区分 |
| 3D 库位 | 车间与区域选择、定位、2D/3D、货架层位、二维码、标牌设置 | 以场景为主，不插入库存流水筛选；继承空间操作与手机手势 |
| 盘点管理 | 提交、库存冻结、差异与审批 | 保留盘点状态、详情和审批流程；不把查看入口隐藏 |
| 备件统计 | 库存健康、按单位与货区统计、操作趋势 | 保留不同单位不可相加及统计周期只影响趋势的规则 |
| 基础维护 | 模型关联/类别模型、设备与备件关系、数据质量修复 | 保留集中入口；不新增已取消的专用模型功能 |
| 工程知识 | 分类、检索、资料/故障、在线阅读、修订、配置及问答 | 青绿主题、侧栏分类、紧凑阅读列表；附件与证据功能保留 |
| 程序分析 | 离线 Siemens/ABB 导入、项目、程序对象、引用与证据分析 | 保留项目栏和证据区域；不新增在线 PLC 控制或写入 |
| 制曲工作 | 组长分类填报、R、任务反馈、本人记录和考评 | 蓝紫主题、手机四个标签一行、日期/休息/刷新紧凑并列 |
| 班长工作 | 自然周记录表、任务派发验收、考评复核、班组设置 | 周表为默认主体；自然周控件、设置和任务入口保持分离 |
| 原粮检查通报 | 截图、问题识别与人工核对、裁切、历史、归档及查看 | 保留整理/查看角色差别，只调整公共控件与弹窗约束 |
| 登录 | 会话认证 | 沿用现有登录，不改变账号及认证机制 |

## 权限与业务边界

- 系统管理员保留最大权限；车间管理员入口可见，业务写入受所属车间限制；全局配置仍按既有管理员规则执行。
- 普通人员备件只读；所属车间盘点提交是现有例外。组长工作填报使用独立工作权限，不扩大备件修改权限。
- 组长不选择他人；班长操作已分配组长；跨车间管理员查看制曲及原粮入口，不能越车间写入。
- 保留周日 08:00 建议评分、班长复核发布，以及管理员手动触发的原流程；配色修改不改评分公式和记录。
- 小程序与网页共用业务接口。本次 Sites 改动只涉及网页展示，不新增原生小程序页面。
- 备件与后续独立模型匹配字段仍是后续数据库工作，本次不创建新字段。
