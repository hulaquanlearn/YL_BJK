# App消防照片预览手势修正（2026-11-14）

App消防点检照片预览补齐双指缩放和双击放大/还原；适屏大小固定居中，只有放大后才能在照片边界内拖动。缩回适屏和关闭重开均还原居中；保持单图、简洁界面及原关闭按钮。网页原预览工具与行为保留。

## 原因与范围

当前Element Plus查看器的触摸逻辑只有单指拖动，没有双指缩放；App之前隐藏了工具栏，形成“能拖动但不能放大”。本次通过App专用工具栏标记挂载独立照片手势，沿用原图片、关闭按钮、焦点限制及滚动锁定；不改照片上传、识别、存储和权限，也不依赖WebView整页缩放。

修改FirePreviewImage.vue并新增fire-photo-gestures.mjs。只有executionMode分支挂载；网页没有该标记，保留原相册与工具栏。缩放范围为适屏的1～5倍，双击切换2.5倍/适屏。放大焦点跟随双指中心，平移按照片实际显示宽高限定，适屏平移始终归零。触摸取消、旋转窗口、关闭与重开清理指针和事件；同一个标记重复渲染不重新绑定，关闭后移除监听与ResizeObserver并恢复图片样式。对库原拖动处理作捕获拦截，避免两套手势同时改变照片。
