## 使用

- 工程知识搜索栏“问 AI”打开居中的“设备故障知识问答”，删除重复介绍和抽屉布局。此入口面向整个知识库。
- 在资料/故障详情或在线阅读的“问 AI”进入，会显示当前资料名称；问题默认结合这份文件。切换到其他资料或全知识库时清空旧对话，避免混用证据。重复提交和调用中的资料切换被阻止。
- 服务端通过条目编号、修订版本读取启用中的真实资料，忽略浏览器伪造的正文、模型或 Key。版本变更返回冲突，文件已删除返回不存在，未提取到正文明确提示重建全文索引，不冒充已经阅读文件。
- 当前文件证据优先，补充系统内设备关系、故障案例和库存证据；回答带知识/备件/设备型号引用，可点击回看。长文使用与问题相关的片段，标明仅为相关片段；文字问答不等于完整理解扫描图纸或图形接线关系。
