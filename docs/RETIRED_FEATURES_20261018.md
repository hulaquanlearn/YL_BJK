## 服务器只读核对与定向清理

先在运行 OpenClaw 的同一用户、profile 和环境下核对版本与实际条目；不要复制输出中的 token、provider Key 或会话内容到公开聊天：

```sh
openclaw --version
openclaw agents list --bindings
openclaw cron --help
openclaw cron list --json
openclaw config validate
```

`agents list` 判断注册状态，单个 `agents/<名称>` 目录不存在不能单独证明没有注册或没有调度。Cron 的启停、移除和 agent 删除命令以该机版本的 `--help` 为准。核对任务具体归属后，先停止该任务/在途执行，再移除调度和专用绑定；备份对应历史会话及独立工作区后再用 `openclaw agents delete <实际废弃ID>` 定向删除。不要对 `robot-program`、共享 agent 或整个工作区执行清空。

当前官方配置写入命令要求本地网关停止；若现场版本同样要求，安排短暂停服并通过原服务管理器停止/恢复，清理后校验配置，再核对剩余 agent、任务和保留功能。不能将“删除 agent 成功”视为 cron、在途任务、外部轮询和共享配置已全部清理。参考 [agents 命令](https://docs.openclaw.ai/cli/agents)、[cron 命令](https://docs.openclaw.ai/cli/cron)、[配置校验与写入](https://docs.openclaw.ai/cli/config)。
