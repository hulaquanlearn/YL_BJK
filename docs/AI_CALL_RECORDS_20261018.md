## 调用通道

网页和微信小程序共用 `/api/ai/chat`，由后端直接调用 DeepSeek，使用已有私有 `DEEPSEEK_API_KEY`。保留设备/工程相关话题限制、站内资料检索、来源引用和模型失败时的检索降级。小程序不存储 Key，不直接请求模型。

原粮周总结固定使用已启用的 DeepSeek 通道，不再回退到 OpenClaw；机器人默认 DeepSeek。生产配置示例：

```dotenv
DEEPSEEK_API_KEY=<服务器已有Key，不提交、不打包>
KNOWLEDGE_AI_ENABLED=true
KNOWLEDGE_AI_MODEL=deepseek-flash
RAW_DUTY_AI_SUMMARY_ENABLED=true
RAW_DUTY_AI_MODEL=deepseek-flash
ROBOT_AGENT_ENABLED=true
ROBOT_AGENT_MODEL=deepseek-flash
AI_AUDIT_DIR=/opt/spare-parts/data/ai-call-logs
ROBOT_LIBRARY_DIR=/opt/spare-parts/data/robot-program-library
```

`KNOWLEDGE_AI_ENABLED=false` 时保留检索，不调用模型。知识问答、原粮总结及 ABB 程序分析均不再经过 OpenClaw；机器人旧兼容通道与地址/令牌/agent ID 配置读取已删除。本站旧 `AI_CONTEXT_TRANSFER_ENABLED`、`OPENCLAW_*`、`ROBOT_AGENT_TRANSPORT`、`ROBOT_AGENT_API_URL`、`ROBOT_AGENT_ID` 不再需要。未操作现场 OpenClaw；核对其他项目后，可归档对应会话并移除本站专用 agent/触发器。不能删除共用 DeepSeek Key，也不应全局删除其他项目的 OpenClaw 配置。

## 机器人每日次数

- 系统管理员没有每日业务次数限制，旧机器人每分钟 12 次限制也对其豁免；同账号/同备份仍防止并发重复写入，系统通用访问保护保留。
- 原粮、制曲、酿酒车间管理员均可调用机器人 AI，每账号每天最多 3 次，跨备份与网页会话共用，北京时间零点重置。
- 一次整份中文注释包含全部分批，只记 1 次；单次提问或修改建议各记 1 次。补充某文件未覆盖例程是新注释任务，计 1 次。
- 模型调用前预占，正常失败释放；首批成功后同一任务继续、暂停、刷新或重启恢复不再重复扣次。已有任务可在额度用尽后继续剩余批次。只允许服务端生成的固定批次，不得借任务 ID 追加问题、修改建议或已完成批次。未完成任务保留 30 天。
- 进程突然终止时，未确认的预占保留，避免重启绕过限额；原注释任务可以继续。次数记录位于 `ROBOT_LIBRARY_DIR/.usage/`，升级、备份和删除备份时均保留。当前机器人库和次数账本要求单 API 进程部署，多实例需改用事务存储。
- 上传、删除、重命名和模型连接维护仍仅系统管理员可执行。普通车间人员只读；原粮员工原有仅查备件限制不变。

本规则针对机器人模块。原粮周总结保留既有额度与材料权限。用户随后要求知识问答采用系统管理员不限、车间管理员每日3次、其他人员不可用，已单独实现知识问答额度，与机器人不合并；网页/App/小程序共用同一知识问答账号额度。

## 个人中心与供应商用量

所有已登录账号可从头像进入个人中心，修改本人显示姓名与密码；账号、角色、车间和岗位只读。`PATCH /api/auth/profile` 仅接受 `displayName`，用户编号来自登录会话，不接受角色或其他账号编号。密码沿用现有校验、原密码验证和全部会话失效逻辑。演示账号密码固定为 `preview`，本地演示不执行真实密码修改。

系统管理员额外看到“API 与 Codex 用量”和“调用记录”。`GET /api/personal-usage/providers` 与 `/records-summary` 在读取密钥、外部请求或本机 Codex 前先校验系统管理员身份。返回结果不含任何密钥、认证文件、原始错误或账号邮箱。供应商读取缓存 30 秒；失败或未提供值显示未知/不可用，不伪造零用量。

- DeepSeek：使用现有 `DEEPSEEK_API_KEY` 调用官方余额接口；显示账户充值/赠送/总余额。本系统记录中的 Token 与全账户账单分开，不估算账单费用。
- GLM：`GLM_API_KEY` 只放后端，不进入源码或包。普通 API 账户使用智谱账户只读接口 `GET https://open.bigmodel.cn/api/biz/account/query-customer-account-report`，返回可用余额、累计消费及可选今日消费；只映射允许的金额字段，未返回的消费显示“未提供”。2026-10-18 15:18 本机通过服务层实测 `status:ok`，余额 9.898829 元、累计消费 0.101171 元。此前接到 Coding Plan 套餐接口，账户无该套餐而返回业务失败；这是接口类型接错，已修正，不能据此判定 Key 失效。业务生成仍使用 DeepSeek，查询余额不发起模型生成。
- Codex：本机通过官方 CLI app-server 的 `account/rateLimits/read`、`account/usage/read` 读取已登录账户额度和累计 Token；不发起模型 turn。只有非生产环境明确设置 `CODEX_USAGE_LOCAL_ENABLED=true` 才启用。生产默认关闭，不复制 Codex 登录文件到云端。云端可配置 `CODEX_USAGE_SNAPSHOT_FILE` 读取脱敏快照，显示采集时间并明确标注非实时。

本机可运行 `node tools/sync-codex-usage.cjs` 生成 `.local/codex-usage.json`。需要云端展示时，由管理员仅同步这份统计快照到服务器私有目录，再设置快照路径；本轮没有向服务器发送文件或配置自动同步。

接口依据：[DeepSeek 余额](https://api-docs.deepseek.com/api/get-user-balance/)、[智谱官方用量插件](https://github.com/zai-org/zai-coding-plugins/blob/main/plugins/glm-plan-usage/skills/usage-query-skill/scripts/query-usage.mjs)、[Codex App Server](https://learn.chatgpt.com/docs/app-server)。

记录包括账号及角色、来源端、功能、模型、时间、结果、耗时、实际模型请求数及上游返回的输入/输出/缓存/总 Token。页面支持按日期、网页/App/小程序、功能、结果筛选和分页，已取消账号搜索；每次查询至多连续 31 天，历史不自动删除。整份注释只占 1 次额度，但实际分批请求仍逐条记录，任务 ID 用于关联。

模型请求、未调用模型的配置失败/额度拒绝、话题受限、检索降级分开记录。Token 未返回时记为未知，不冒充 0；Token 不等于实际账单金额，未估算费用。不记录 Key、Authorization、用户问题全文、回答全文、工程资料摘录或机器人源码。来源端由客户端声明，仅作来源标识，不能用来授予权限或绕过额度。网页与原生小程序分别传 web/miniprogram；安卓 WebView 增加 DigitalWorkbenchAndroid/1.0 标记，网页请求据此传 android，微信内嵌页按 miniProgram 标记识别。页面筛选只提供网页、App、小程序。缺失标记的历史记录保留真实审计值，界面以“—”显示，不把未知历史伪造为网页；需要重编译安卓壳才能带上新增标记。来源字段不用于权限判断。

记录写入 `AI_AUDIT_DIR`；未设置时为 `server/uploads/ai-call-logs`，不挂载静态服务，不入 Git/包。请求先持久化开始记录，再调用模型；记录目录不可写时拒绝发起模型请求。响应结束后写入结果；若进程突然退出，已有开始记录保留为“处理中 / 结果待确认”，不能据此声称模型没有扣费。记录只从此版本实际运行后开始，旧版调用无法追补。

后续发布需同步 API 和完整网页构建，并重新发布带来源标识的小程序源码；真实微信登录/真机和生产 MySQL仍需现场复核。只更新 API 可以先让旧小程序改走 DeepSeek，但其来源标识不能完整识别。
