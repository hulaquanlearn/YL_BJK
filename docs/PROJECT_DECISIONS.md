# 项目需求决策记录

## 2026-10-10：模型按名称绑定与库存界面

- 用户明确：备件通过台账“模型名称”字段精确匹配库内模型；保存对应模型 ID，多件备件可共用同一模型。补齐库内空模型资源时保留原名称、ID 和已有绑定，不按物料编码自动替换到细分模型。
- 名称模型可为通用外观示意；193 项原目录中的 11 个空模型补齐，厂家尺寸与具体规格外形仍未核实。
- 详情预览标题用“模型名称（ID 编号）模型”，去掉“单件3D模型”和重复名称行；绑定 / 更换放到底部，与编辑信息同一操作区。
- 库存概况采用紧凑指标加分单位数量区；常规操作用钢蓝 #2F6FAE，悬停 #245887，库存预警保持语义颜色。
