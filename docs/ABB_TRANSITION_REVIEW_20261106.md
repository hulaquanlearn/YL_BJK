# ABB 过渡异常独立复核 · 2026-11-06

结论：当前受保护 BaseMod 的替代路径未通过轨迹验收。左右甑均复现 J6 大幅绕转与整斗出锅时穿入锅体 CAD；不能把全流程执行结束视为动作正确。本轮只读复核，不改 DSH 独占源文件、不部署未验收路径。

## 方法与复现

使用真实酿酒备份 `.local/abb-flow-20261105/report.json`，当前服务端解释器、当前前端 IK/运动准备器，以及真实 `tool-640.glb` / `gujing-pot.glb`。目标高度40 mm、90 L斗容、左右甑分别从工位 home 姿态运行；每次均559条运动、10条受保护模拟过渡、正常结束。

脚本 `.local/abb-pendant-layout-20261106/transition-audit.mjs`：每2°关节变化采样；工具 CAD 每8个顶点取一个，共60729点，按页面原有挂载矩阵与机器人校正变换转换。先用保守锅壁/锅底范围筛选，再对实际摆放后的锅体网格做射线奇偶穿越确认内部点。不修改标定矩阵，不改变源速度。输出同目录 `transition-audit-left.json` / `transition-audit-right.json` 与 `.log`。

这是查出穿模的正向证据，稀疏采样没有发现相交不能证明安全。未覆盖全部三角形、工具护罩全行程、机器人其余连杆、锅盖及扫沿路径；不代表真机验证。
