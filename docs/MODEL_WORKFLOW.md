# 备件模型维护流程

当前模型及待核对状态见 [模型修正记录](MODEL_REPAIR_20261023.md) 与 [待核对清单](MODEL_PENDING_20261023.md)。本文件替代旧OpenClaw建模交接文档，不把历史542条候选或旧51类资源数量当作现网覆盖结论。

1. 只读核对当前有效备件编码、名称、品牌、规格与现有绑定；不将库存、价格、库位、账户或整份台账发送到外部服务。
2. 用厂家、完整型号、极数、安装形式与系列后缀区分外观。电机保护器不等于电机、附件不等于总成、带座轴承不等于裸轴承；多个候选不自动选第一项，不能仅按名称子串批量覆盖。
3. 搜索只发送必要的公开产品描述，优先厂家目录和外形图。记录来源、页码及近似范围，不把第三方可下载CAD自动视为允许再分发。
4. 外观示意、尺寸参考与厂家模型分别说明。资料不足列“待核对”，不能声称制造精度或真实颜色；隐藏的内部构造不得依据名称编造。
5. 优先保留正确模型ID及人工绑定；确需拆分不同外形时，按具体备件ID/型号逐项制定计划。计划包含目标身份、原绑定、目标模型、来源与待核对项；数据变化时重新核验，不自动执行历史绑定计划。
6. 模型含原材质及有意义的部位分组。选择部位应明显高亮，引线放在外侧；完整展台按几何底部放置，库位紧凑详情仅展示对象。照片与模型分开保留。
7. 检查实际GLB几何、空孔、分组覆盖、文件哈希、显示比例、旋转与底部接触，再进行桌面/窄屏和真实接口权限核验。构建通过不代表与所有实物一致。
8. 修改按AGENTS.md默认同步授权执行，部署前备份，失败回滚。旧资源从有效部署退出后可恢复回收；有效上传、模型记录、业务数据及必要回滚副本继续保留。

当前方案在 `tools/modeling/model-review-plan-20261023.json`，生成器 `tools/modeling/apply-model-review.mjs`。日常核对以有效备件、模型库及绑定接口和实际GLB为准；资料候选可使用 `tools/modeling/audit.mjs` 只读整理，不把历史类别关键词覆盖率作为当前绑定或模型正确性的结论。
