# ABB 连续上甑、料面与操作区整改 · 2026-11-05

状态：2026-11-05 18:56 已同步并核验。版本保持 V1.9.10。

## 本轮范围

- 程序模式与侧栏展开分开。收起侧栏继续运行，底部保留程序控制；绿色程序分析和退出程序模式相邻，移除重复标题、20×及程序模式中的360°/旋转。参数值、单位、输入/选择框统一高度与居中，底部同时显示执行状态、文件行和源码。模型右键拖动平移；示教器只交换上方模型展示，帮助/状态与关节区保持原位。
- 全流程从 main 反复接料、铺料，达到体积对应的预设高度才收尾；选择例程只运行该例程。空斗阈值为低于1L，保留残余量，补料只补斗容差，最后不足1L的目标余量仍可排完。
- 暂存斗单一库存驱动链板、出料闸板和接料反馈。接料阶段布料斗挡料板关闭、皮带/打散停止；铺料阶段打开，分别读取皮带和打散转速。离线推导执行器状态与原始RAPID输出分开，不声称现场PLC已执行这些互锁。
- 重新开始同时复位程序与源 pRobHome 对应的模型姿态；回归接料位放在设备动作首项。起始640斗包围盒与暂存斗实体无相交检查通过。
- 料面改成共享顶点的连续三角曲面，不再显示实例方块。按实际运动轨迹/斗口宽度累计，局部守恒摊散；暂停不增加体积。深褐酒醅使用不规则颗粒纹理，皮带浅黄。
- 沉积分布使用左右锅各自完整uframe/oframe，ABB Y到场景负Z；逆解锥锅高度带来的径向扩张，避免高料面时落料位置漂离斗口。
- 离线布料目标在保留源TCP对源层高间距的基础上跟随局部料面，并检查斗口覆盖范围；接料返回进锅点使用全锅最高料面加过渡间距。原ZIP/源目标不修改，运动事件附surfaceFollow。竖直回落不计入铺料体积。
- 边高中间低通过体积归一化目标剖面实现；本轮边中高差40mm为离线展示参数。800mm指体积等效装填高度，最终局部高度约780–820mm，不是用增加总料量堆高边缘。
- 消防网页固定短列，将剩余宽度给位置，记录操作固定右侧。

## 速度依据与限制

默认100%/1×。移除统一40°/s的人为限速，按ABB IRC5产品规格IRB6700-150/3.20六轴上限100/90/90/170/120/190°/s、RAPID速度数据的TCP与姿态分量、VelSet倍率和TCP上限共同约束。程序执行不再误套手动单点的250mm/s限速；5×/10×明确是演示加速。

来源：[ABB IRB6700 IRC5产品规格3HAC044265](https://library.e.abb.com/public/1191b23d5d564388a77d636084b9ae0e/3HAC044265%20PS%20IRB%206700%20on%20IRC5-en.pdf)；[ABB RAPID参考手册3HAC050917 Rev F，VelSet及speeddata](https://library.e.abb.com/public/b227fcd260204c4dbeb8a58f8002fe64/Rapid_instructions.pdf)。

这不是Virtual Controller。AccSet保留为源参数元数据；未实现负载、控制器加速度/拐角规划和真实热成像闭环，也没有实机节拍对照，因此不声称与现场控制器逐毫秒同步。
