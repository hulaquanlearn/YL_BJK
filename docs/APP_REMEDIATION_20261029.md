## AI Key 设置

新增网页版系统管理员入口：个人中心→API 与 Codex 用量→当前 AI 接口。支持选择当前 DeepSeek 或 OpenAI 兼容接口，编辑接口地址、模型名称与 API Key。连接测试用少量固定文本验证接口、凭据和模型调用，不代表消防图片识别通过；图片能力单独显示。无效配置不覆盖在用配置。

新 Key 只提交服务器，旧 Key 不返回浏览器。私有覆盖文件 `server/.env.ai-settings` 不入仓库和发布包；历史配置保存在私有目录以便回滚。保存后知识问答、履职总结、机器人助手、消防识别及余额读取统一使用新 Key。首次没有覆盖文件时沿用现有 `.env`，本轮部署不替换实际生产 Key。
