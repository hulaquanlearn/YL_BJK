## 照片可见事实（不作实测尺寸）

- 锅盖是**大直径、薄壁、弧面/碟形钢壳**：外侧凸、内侧凹，边缘有连续翻边；不是平板。
- 盖背面中心有**圆形轴座/轮毂**，轴座通过一条**长摆臂/摇臂**（照片中为带多排螺栓/孔的厚板）连接到锅体后下方的固定铰点。
- 摆臂下方/后方有**液压油缸**：缸体下端固定在机架/基础附近，活塞杆上端与摆臂或中心轴座附近铰接；照片中油缸呈近竖直/略后倾姿态。
- 开盖时整个“盖+中心轴座+长摆臂”绕后下方固定铰点转动；不是简单的锅沿前铰链，也不是中心点原地翻转。
- 现场有锅沿、机架、横梁、电控箱、接料设备等近体障碍；锅盖完全打开后需有稳定停位/后挡，不能只凭油缸保持。

## 机构建议

1. **保持“后下方固定铰点 + 长摆臂 + 中心轴座”四连杆/摆臂关系**
   - 铰点应位于锅体后方、低于盖中心；中心轴座应在盖背面中心附近，摆臂两端分别接铰点和中心轴座。
   - 不要改成锅沿前铰或两侧短销；照片中没有这种结构。
   - 开盖旋转轴平行锅体横向（X），盖和摆臂作为近似刚体绕固定铰点转动；中心轴座是盖的连接点，不是独立转轴。

2. **碟形壳与翻边**
   - 保持外侧凸/内侧凹的连续旋转曲面，中心厚度/深度按照片为浅碟形，不要退回平板或方盒。
   - 外缘做成连续翻边/圆角，闭合时与锅沿留有明确间隙或密封关系；不要让薄壳边缘像刀口。
   - 中心轴座背面应有加强/法兰/多颗螺栓；照片显示中心轮毂与摆臂有较大连接面，单点细轴会不真实且碰撞包络错误。

3. **长摆臂几何**
   - 摆臂应从铰点到中心轴座形成实体长臂，厚度和宽度要覆盖照片中的多排螺栓板；当前 box 梁可作为一级近似，但应检查它与盖背面、锅沿、油缸杆的空间关系。
   - 摆臂不应穿过碟形壳背面；中心轴座应坐在壳背面加强区，而不是悬在壳外。

4. **液压缸**
   - 下铰点在机架/地面，上铰点在摆臂或中心轴座附近；用两铰点距离约束，缸体长度和杆伸出量必须在物理行程内。
   - 当前 `stroke=length-barrelLength` 允许出现负杆长/杆缩进缸体的显示；应加最小/最大行程夹紧和 `rod.scale.y>=0` 保护。
   - 缸体不要与摆臂扫掠区、锅体/基础相撞；油管/接头不应穿入运动包络。
   - 完全开/完全关时避免油缸过死点；照片只能定性，不能据此定行程。

5. **停位/稳定性**
   - 完全打开应有后挡/机械限位或稳定重心位置；仅靠油缸保持不符合现场重盖的安全直觉。
   - 关闭位置也应有机械止挡/密封面，避免薄壳直接压锅沿。
   - 当前 `set()` 的 100° 是展示值；建议作为可配置上限并加入限位/停止状态，不要宣称实测角度。

## 碰撞建议

1. **扫掠检查必须覆盖所有运动件**
   - 当前 `intersectsSweep` 的扫掠顶点只来自 `hinge`；液压缸体/活塞杆、底座、摆臂/中心座若也在运动或可能进入包络，应一起加入扫掠或单独检查。
   - 静态障碍至少包括：锅沿/锅体、后机架/横梁、地面/基础、电控箱、接料设备、护栏，以及**机器人/工具在开盖可能的位姿**。
   - 安全余量建议明确参数化（如 60–100mm 展示余量），不要把 `expandByScalar(.06)` 当成现场安全距离。

2. **重点检查姿态**
   - 0°（闭合）：壳外缘、中心轴座、摆臂、油缸均不得碰锅沿/锅体/机架/接料设备；薄壳边缘与锅沿间隙可见。
   - 中间 25°/50°/75°：盖外缘扫过锅后机架/横梁；长摆臂扫过油缸和电控箱；液压杆/缸体不应与摆臂自交。
   - 100°（打开）：盖重心/外缘不得撞后墙/横梁；油缸不得过死点；开盖后应能稳定停住。
   - 如果机器人正在锅口或接料位，盖不能作为独立动画穿过机器人；应有限位/联锁/禁止开盖逻辑，不能在离线模型中互相穿过。

3. **与现有 `sweptBounds`/`intersectsSweep` 的集成**
   - 先用 `sweptBounds()` 做粗筛，再用三角形精确检查；把障碍物克隆并膨胀，记录碰撞时的 `amount`、障碍物 id、最近点。
   - 增加“碰撞时停止/回退”的离线显示，不要让盖继续穿模。
   - 自交检查至少包括：摆臂 vs 盖壳、摆臂 vs 油缸杆、油缸体 vs 铰座/基础、盖外缘 vs 锅沿。

## 不建议

- 不要把照片中未标定的直径、厚度、铰点、油缸行程写成现场实测值；模型应继续标 `estimated:true`。
- 不要把锅盖的 `Do105/Di105` 液压控制与红外 `DO176/DO179/DI178` 混为一谈；本轮只做机构几何，不伪造液压到位信号。
- 不要用平板替代碟形壳，也不要用短侧铰替代照片中的后置长摆臂。
- 不要让油缸杆负长度、油缸穿过摆臂、盖穿过锅沿或机器人；这些应在修改后逐姿态检查。

## 建议的最小验证

- 0/25/50/75/100% 开度的壳、摆臂、油缸、锅沿/机架 AABB + 三角碰撞；
- 油缸两铰点长度、杆长上下限、无负缩放；
- 开/关终点停位；
- 机器人/工具在锅口、接料位时的静态包络；
- 与照片对照的轮廓目视（不代替实机验证）。
