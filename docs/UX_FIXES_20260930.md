# 本轮源码整改记录（2026-09-30）

本轮遵照用户要求，只修改源码和静态检查相关逻辑，未执行测试、构建、打包或部署。

- 每周工作记录标出在线文档事项，在输出依据列展示当前文档名称和入口；单条记录保留填报时使用的链接。
- 填报事项列表显示已绑定文档入口。
- 记录表按单条记录的事项快照检查材料；必须上传工作截图的事项不再把固定链接视为已上传截图。
- 库存状态筛选按钮增加背景、边框、已选条件文字；列表上方显示可清除的条件标签。
- 选中及定位货架的框架、层板恢复黄色；2D 和侧栏选择状态同步显示黄色。
- 业务切换菜单增加实际路由链接，保留键盘菜单跳转。制曲组长仍使用只读备件权限，未扩大修改及审批权限。
- 库存筛选缓存按账号区分，避免使用另一账号的筛选条件。
- 库存列表读取失败显示持续错误和重试入口，避免被误认为库存为空。
- 从评分标准跳转在线文档设置时保存内存中的标准草稿，返回后恢复；绑定文档不再重新加载并覆盖草稿。

待确认：当前前后端源码均允许制曲组长读取备件，尚未取得其“无法进入”的具体错误或点击后状态，因此不将此项标记为根因已解决。后续统一测试需覆盖真实组长账号的业务切换、库存读取、修改权限拦截及审批限制。
