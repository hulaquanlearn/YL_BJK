# V1.9.10 核验与交付记录（2026-10-09）

## 本轮修复

1. PLC/Siemens TIA 与 ABB RAPID 分析暂停：移除工作台/导航入口，不构建分析页面；旧书签转到工程知识，分析/代理 API 返回 410。部署包不含解析代理安装工具，历史程序数据和相关源码保留。
2. 新 `/parts/batch-model` 被前面的旧接口 410 规则遮挡：移除重叠规则，恢复绑定/解除；加入真实 Express 请求、跨车间/共用资源拒绝和整批回滚检查。
3. read-excel-file 9 返回工作表集合，旧代码当作行数组处理：模型绑定改为查找带表头的工作表，备件/设备改用 readSheet 行接口；以真实 XLSX 上传验证。
4. 旧打包脚本漏带 `server/data/ledger-model-catalog.json`：仅打包该运行时目录文件，排除库存资料；独立核验目录引用模型、内外 SHA256 及源码一致性。
5. 更新 sharp、proxy-addr、source-map-js、axios、DOMPurify、Vue 及相应依赖；删除无调用的 http-proxy-middleware。没有强制跨主版本升级。
