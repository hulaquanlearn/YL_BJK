# App 入口、登录与后台更新（2026-10-28）

目标安卓版本：1.9.10-android.13，整站保持 V1.9.10。当前状态：已发布，北京时间2026/10/28 13:19:31。

## 使用变化

- 消防点检回到工作台的“工作管理”分组，和履职入口同行；底栏为“工作台／我的”，不再单列点检。仅显示当前账号已获授权的功能。
- 启动读取已有会话；未登录只显示一份原生登录表单。登录成功后等待授权目录准备完成，再显示原生工作台，避免露出重复的网页登录、门户展示页。网络或初始化失败可重试，登录切换超时保留原表单。
- 我的保留个人资料、检查更新和退出登录。“关于与隐私”不再是一级菜单，登录页可直接阅读隐私说明；更新面板底部保留隐私说明与可点击备案号。已有同意状态沿用，不因菜单调整重复确认。
- 登录后自动检查可用版本并在后台下载。更新面板显示实际检查、下载、校验、就绪或失败状态；下载完成后可稍后安装。安装仍需 Android 系统确认。
- “清理安装包”清除本机下载的 APK、未完成下载和更新元数据，显示实际占用大小；不清账号、密码、业务记录或照片。进行中的下载先停止再清理，避免刚清完又被轮询下载。

本轮仅发布同包名、同正式签名的 APK 与独立更新清单；网页、API、数据库和小程序不随本轮修改。旧安卓客户端需先安装 android.13，之后才具备新的后台下载与安装包清理行为。覆盖安装保留现有会话和本机凭据。
