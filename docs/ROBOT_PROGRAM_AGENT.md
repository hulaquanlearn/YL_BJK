## 使用与权限

- 备份列表工具栏统一提供导入、导出、重命名、搜索及刷新，卡片右上角 × 删除。移除独立上传区、独立统计条、ZIP 哈希展示与次数说明卡片。
- 系统管理员可导入、删除、重命名及分析；三类车间管理员可分析；其他获授权人员仅查看已有源码、注释和分析。原粮员工仅查备件的原权限不扩大。
- 后台仍执行系统管理员不限次数、车间管理员每天 3 次：整份分批注释算 1 次，提问/修改建议各算 1 次，正常失败不扣次，继续同一未完成注释任务不重复扣次，北京时间零点重置。
- 导入后默认自动生成中文注释；刷新、切换备份及重新登录只读取已保存内容，不重复调用模型。未配置或服务失败时说明原因并保留备份。
- 对话区统一为一个“发送”按钮：模型在同一次请求中理解解释/提问或修改代码的需求。普通解释不生成修改，含糊需求先澄清；修改仅作为校验原文和行号的建议展示，不写回备份。发送不增加额外的分类模型调用，仍计一次业务用量。
- 引用可以定位原始行号；只看注释、下一条、例程与调用、原始源码仍可使用。不可读模块不猜测或解密。修改建议单独审阅，确认后才加入导出阅读包，不写回原备份或控制器。
- AI 注释与修改仍须按现场程序、RobotStudio/控制器和设备条件核对。行号/原文校验通过不等于语义或运行验证通过。

## 后端配置

后端固定调用 DeepSeek 官方接口。旧 OpenClaw 兼容代码及其地址、网关令牌、agent ID 读取已删除，ROBOT_AGENT_TRANSPORT / ROBOT_AGENT_API_URL / ROBOT_AGENT_ID 不再使用。知识问答和原粮总结也已改为 DeepSeek。不要把仍供其他系统使用的 OpenClaw 全局配置一起删除，现场定向清理见 [废弃功能说明](RETIRED_FEATURES_20261018.md)。

服务器私有配置：

    DEEPSEEK_API_KEY=<服务器已有 Key，不提交、不打包>
    ROBOT_AGENT_ENABLED=true
    ROBOT_AGENT_MODEL=deepseek-flash
    ROBOT_LIBRARY_DIR=/opt/spare-parts/data/robot-program-library
    AI_AUDIT_DIR=/opt/spare-parts/data/ai-call-logs

密钥与业务内容只由服务端整理发送；账号、许可证和 HOME 日志不发给模型。当前最多发送当前备份 4 轮历史，不复用其他账号或备份的会话。

## 保存、删除与导出

服务端持久化多份原始 ZIP、注释、分析、进度及最近问答。ZIP 内容哈希用于去重、引用和版本冲突检查，在界面中不展示。显示名称不参与磁盘路径拼接。

删除需要系统管理员确认并验证当前版本；分析中禁止删除。内容移入库内私有 .deleted 归档，并写入删除标记，防止旧浏览器缓存自动迁回。显式重新导入允许重新建库，不恢复旧注释。

原 ZIP 可能含账号或许可证，所以没有公开原包下载接口。导出的“中文注释阅读包”只包含筛选后的程序/配置原始字节、另存的中文注释阅读稿、说明与分析；确认修改后额外包含待验证建议稿。

升级保留 ROBOT_LIBRARY_DIR（包含 .usage 和 .deleted）、调用记录、业务数据库及上传，不作为静态目录、不放 Git/部署包。当前文件库要求单 API 进程，多实例需要改为事务存储。最多 100 份、单 ZIP 20 MiB、单分析记录 2 MiB、累计 2000 条注释；超限保留旧结果并提示。

旧版同源管理员浏览器的最近一份本地记录会迁移到新备份库；删除标记会阻止自动复活。此迁移仍有明确的数据保留用途，本轮没有删除迁移逻辑。
