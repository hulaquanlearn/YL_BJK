## 清理一致性

- 仅删除管理员确认的照片 BLOB，并从其所属材料的普通、每日、每月以及旧周期快照中移除图片 ID；不删除履职文字、总结、报告、原提交状态或既有事件审计。跨周月度视图从源材料读取，源事项关联同步更新；以前已独立复制的照片拥有不同编号，不会误删。
- 批量清理只提交预览中逐项编号和版本，覆盖所有分页，最多 1000 项。事务先锁定并验证全部材料，再执行删除；版本变化或照片缺失使整批失败并回滚。
- 照片清理与履职保存/提交/上传使用同一报告行锁。同一份报告的多张照片一起清理只递增一次报告版本，旧客户端必须刷新。清理本身不把报告更新时间改成新日期。
- 记录 `work_storage_audit` 的历史/关联标记、所属报告和删除大小；履职事件显示“管理员清理验证照片”。历史提交事件继续保留，不改写成没有发生过。
- 不需要新增数据库迁移，沿用现有履职、考勤和清理审计表。逻辑释放字节不代表 MySQL 数据文件会立即缩小。
