## 二、真实运动轴与单位

程序把行车当作 16 轴关节式设备控制（A0–A15，对应 `getRobotPos(1..16)`）。轴位置统一由 `Yx(原始值)/1000.0` 得到：**直线轴 mm、旋转轴 rad（原始值按 0.001 单位存储）**。9 个机构、16 个伺服轴：

| 真实轴 | 机构 | getRobotPos | 原始量来源 | 双驱/同步 | 原点保存位 |
|---|---|---|---|---|---|
| A0/A1 | 大车行走 | 1/2 | Yx(1037)/Yx(1038) | 双驱 | 0x3 |
| A2/A3 | 伸缩小车行走 | 3/4 | Yx(1039)/Yx(1040) | 双驱 | 0x0C |
| A4/A5 | 抱斗升降 | 5/6 | Yx(1041)/Yx(1042) | 双驱，同步偏差反馈 | 0x30 |
| A6/A7 | 抱斗开合 | 7/8 | Yx(1046)/Yx(1047) | 双驱，偏差自动纠正 | 0xC0 |
| A8 | 抱斗旋转 | 9 | Yx(1416) | 单驱 | 0x100 |
| A9/A10 | 转运行走 | 10/11 | Yx(1417)/Yx(1418) | 双驱 | 0x600 |
| A11/A12 | 转运升降 | 12/13 | Yx(1419)/Yx(1420) | 双驱，同步偏差反馈 | 0x1800 |
| A13/A14 | 转运翻转 | 14/15 | Yx(1421)/Yx(1422) | 双驱，同步偏差反馈 | 0x2000（A14 无原点保存位） |
| A15 | 2D 云台旋转 | 16 | Yx(1423) | 单驱 | 0x8000 |

- 旋转轴不是连续 360°：程序只有两个目标位——`0` 和 `PI*0.5`（90°）；换向对抱斗张开量有阈值条件（脚本阈值为程序常量，具体数值以现场配置为准），不是在任意张开量下都可换向；回正判定 0.02 rad。
- 翻转轴为**双向 0→±π**：倒糟时可达 3.0–3.14 rad（约 172–180°），回水平目标 0，容差 0.005 rad；方向由 `getFlipDirect()`（Yx(1901) 倒料方向）决定。
- 2D 云台目标为 0 或 `PI*0.5`（含约 0.13/0.14 rad 偏置），回零判定 0.1 rad；窖池区/设备区极限由 Yx(1952)/Yx(1953) 配置。
- 同步保护：程序在轴 6/8/13 偏差超 100、轴 15 偏差超 2 时提示“同步轴差值过大，请重设原点”；开合偏差 >3 mm 时写入纠正量 499 自动纠正（这里的“100/2”是程序原始数值，物理单位以控制器轴配置为准，不当作现场标定）。

单位与配置补充：

- 大车定位读码条码值在程序中按 mm 直接参与坐标运算（设备区/窖池区分界条码 10000/15000）；小车、周转小车用激光测距值（mm）。
- 各轴速度由软件侧 `CoordinatePV1–PV8` 配置（x 运行、y 运行、z 上升、抱斗旋转、转运行走、转运升降、翻转、2D 回零）；具体数值不在 `.rbt4` 内。
- 力矩按 N·m×1000 上报；读码相机参数为编码宽度 mm×10、位置 mm、速度 mm/s、快门 us。

## 三、初始/静止位姿（与上一轮演示模型的对照）

程序对“可安全移动”的静止状态有明确定义：

- **抱斗**：升降最高点且完全闭合——`|A4-Yx(1811)|≤5 mm` 且 `|A6|≤10 mm`。
- **剪刀叉（转运）**：停在移动安全高度——A11 等于 `Yx(1883)`（大车运行高度）或 `Yx(1884)`（小车运行高度），±2 mm。
- **翻转**：回正 `|A13|<0.02 rad`（水平）。
- **2D**：回零 `|A15|<0.1 rad`，扫描模式 300 缩回 / 301 伸出。

上一轮示意模型的初始态（hoist 顶端、grip 闭合、transferHoist 顶端、flip 0）方向一致，但**缺 2D 轴**，且旋转、翻转、开合的行程范围与真实程序不同（见第六节）。

主程序 `OnMain` 的结构：

1. 周期检查同步轴偏差；读取平板/共享内存里的目标（目标字打包为“位置 + 出池号 + 入池号”）。
2. **半自动模式**：平板命令码 101 大车移动、102 小车移动、103 抱斗升降、104 抱斗开合、105 抱斗旋转、106 剪刀叉移动、107 剪刀叉升降、108 剪刀叉翻转、200/201 插销伸缩、202/203 2D 伸出/缩回、208 大车带轮补偿、300–399 2D 扫描模式；半自动联动指令 1–19 直接进入 `robotOpt(act,pos)`。
3. **全自动模式**（PLC 调度）：行车上有料斗时按斗类型（空斗/入池斗/丢糟斗/凑料斗）执行凑料倒糟、丢糟、入池/踩窖、进糟位倒糟、取糟、空斗位放斗、临时位；无料斗时按凑料请求/出糟位/空斗位取斗。

主要调用关系：

- `OnMain → robotOpt`：按动作号分派到 `vectorOpt`（取/放斗）、`flipHopper`（入池）、`AutoDigLess`（出池）、`transfer`（转运）、`antiTransfer`（反运）、`transferTop`（转移覆盖糟）、`press/press2/press7`（踩窖/抓平）、`digBottom`（池底）、`getCover`（取盖）、`startScan/waitScan`（扫描）。
- 取/放斗：`vectorOpt` → 辊道锁定 `hopperLock` → 2D 扫描 303/304 → 转运升降到点位高度并下探 80 mm → 料斗检测 → 插销伸出/缩回 → 转运升降回移动高度 → 2D 伸出。
- 进糟位倒糟：`vectorOpt` 内 `transYZRmove` 三段，翻转 1.047 → 1.9 → 3.14 rad，y 依次 -400/-800 mm，随后大车退 10000 mm、翻转回 0。
- 入池倒糟：`flipHopper` → 2D 扫描 310 → 大车/小车/转运联动 → `transYZRmove` 十段，翻转 0.471→0.810→0.958→1.044→1.188→1.519→1.731→2.268→2.868→3.0 rad，y/z 同步推进 → `transferFlip(0)` 回水平 → 可选抓平。
- 转运：`transfer` → 2D 缩回 → 转运升降到 `Yx(1895)` 转运高度 → 抱斗旋转到 0 → 剪刀叉与抱斗贴合（必要时提前张开行走）→ 抱斗张开到 `Yx(1873)` 最大开度 → **函数返回，不自动回安全姿态**，后续姿态由下一次调度决定。
- 取盖：`getCover` → 张开抱斗并对位盖体 → **暂停等待人工确认吊带绑好** → 分段提升/横移 → **暂停等待人工确认吊带松开** → 闭合抱斗提升回安全位；程序没有自动夹盖或插销锁盖动作，不能把人工步骤写成自动动作。
- 反运：`antiTransfer` 两轮——转运升降到转运高度、开合到最大并下降、闭合抓料、上提、大小车移动到撒料点、下降、开口放料。
- 出池抓糟：`AutoDigLess` → 2D 扫描窖池 → 张开/下降/闭合/上提的分层循环（含抓平、池底、双轮底分支）。
- 运动原语：`xmove/xmovePos`（大车，条码 mm）、`ymove/ymovePos`（小车，激光 mm）、`zmove`（升降 mm）、`digmove`（开合 mm）、`switchBaodou`（旋转 0/90°）、`transferMoveX/XPos`（转运行走 mm）、`transferMoveH`（转运升降 0..Yx(1899)）、`transferFlip`（翻转 rad）、`rzmove`（升降+开合联动）、`transYZRmove`（转运行走+升降+翻转联动）、`xytransmovePos`（大车+小车+转运联动）、`ymoveBoth`（抱斗/剪刀叉交换位置）。

安全/默认参数（脚本常量，部分会被按车间配置覆盖，不能当作统一现场值）：`laser_save=3000 mm`（碰撞检测范围）、`height_move=1200 mm`（平移高度安全距离）、`height_pool=610 mm`（一至七车间在 `OnMain` 中覆盖为 1100 mm）、`teach_delta_x=-1355`、`teach_delta_y=-528`、`safe_delta_x=4000`、设备区条码 10000、窖池区/设备区条码分界 15000；升降 `0..Yx(1811)`、最低 `Yx(1815)`；转运升降 `0..Yx(1899)`；开合 `0..Yx(1873)`；转运行走 `Yx(1894)..Yx(1893)`。另有急停、大车前后限位、小车/转运跨侧限位、卷筒上下限位、防坠电缸、起重量限制器、门开关、插销、辊道锁定、同步偏差等联锁。

## 七、与上一轮示意模型的差异与建模建议

上一轮模型是按培训资料 CAD 截图做的 8 轴比例示意（已上线 `intelligent-crane-20261106`）。按本轮原工程复核，建议下一轮（由 Codex 决定并登记）：

1. **轴数**：真实为 9 机构 16 轴（含 2D 云台 A15），演示模型只有 8 轴；建议补 2D 旋转轴，或在资料页单独列出 A15。
2. **旋转**：真实只有 0/90° 两个位置；换向受张开量阈值条件限制（阈值以现场配置为准）。示意模型原来的 ±180° 连续旋转应改为 0→90°（或至少限定在 0–90°）。
3. **翻转**：真实 0→±(≈172–180°) 用于倒糟，不是 90°；建议翻转演示上限扩到 180°，并区分倒料方向。
4. **开合**：真实以 mm 计，0..Yx(1873)（运行值），不是固定角度上限；演示可用比例但标注“开合尺寸为配置值”。
5. **双驱**：升降、开合、翻转、转运行走、转运升降均为成对驱动，并有同步偏差保护/纠正；模型/资料页可体现“双驱 + 同步偏差”概念，但不要显示为现场联锁值。
6. **初始位姿**：升降最高+闭合、转运升降到移动高度、翻转水平、2D 回零；上一轮方向一致，建议补 2D=0。
7. **演示动作顺序**：建议按真实调用做“取斗 → 大车/小车移动 → 入池（分段翻转 0.47→3.0 rad）→ 出池（扫描+抓放循环）→ 转运/反运 → 翻转回水平”，而不是现在的五段固定往返。
8. **示意与真实分开**：模型比例、颜色、走台、机构位置仍按图示意；真实轴表、单位、初始位姿、动作名称/顺序可放到技术资料/程序说明中，不写内部 IP、PN 名称、账号、人员、调试参数。
