## 手机操作重组

- 原生顶层导航按工作台、备件、工程、工作、我的组织；只展示当前账号获准进入的业务板块。工作台提供现有功能查找与会话内常用/最近入口，不编造库存、待办或业务统计。按用户最后要求，手机网页和原生首页均去掉欢迎语、日期、姓名、角色及状态块，直接显示功能；“我的”中的个人资料继续保留。
- 库存、补货、流水、盘点、设备关联备件和数据检查使用手机记录卡片；桌面表格在手机模式隐藏，保留原选择、导出、详情及写操作权限。补货和盘点的选择仍沿用原业务规则。
- 机器人阅读器在手机上切换“读程序 / 逻辑助手”，共用当前备份及已挂载的源码、对话和分析结果。点击 AI 源码引用切回源码并定位；切换面板不重新分析、不清空问题或注释。
- 工程知识改为类型切换、可展开分类、搜索及单列资料卡片；详情、在线阅读和问 AI 沿用现有数据与出处。编辑、附件、索引、修订和未保存提醒继续使用原处理函数。
- 考勤使用人员/班次记录卡片和日期/提前时长排序，进入原核查时间线与备注；切换记录仍执行未保存备注确认。卡片和导出使用同一筛选结果，不改考勤判断规则。
- 履职保留逐项填报、保存下一项与草稿提醒。手机审核列表提供选择和批量导出；管理员人员分配和职责模板使用字段卡片，沿用原保存接口和权限。
- 个人中心通过手机内容选择器进入资料、安全和获授权管理内容；数据管理按分类及资料条目展开，原预览、确认、版本保护和清理边界保留。

主要源码为 `spare-parts-web-release/src/components/MobileWorkspace.vue`、`src/utils/mobile-workspace.mjs`，以及 `mobile-app.css`、`mobile-spare.css`、`mobile-business.css`。记录卡片与桌面表格只显示当前模式对应的一份；隐藏表格保留的选择接口用于复用已有选择逻辑。

## 权限与数据保护

手机目录直接使用已有 `canReadFeature`，服务端继续负责真实数据与操作授权。原粮员工仅开放备件查询、详情、库位及本人维护；没有通过增加手机入口扩大履职、考勤、工程、出入库或管理权限。

AI 继续使用服务端 DeepSeek。原有账号配额、北京时间重置、失败处理和审计保留；机器人注释生成/继续/补充仍仅系统管理员。知识与机器人配额仍按各自规则执行，不能因换界面或清理调用记录重置次数。

数据库、库存台账、出入库、审批、上传、私有配置、机器人原备份及成功分析、模型 ID/绑定、实物照片、知识版本、配额及审计沿用原存储。考勤仍仅保留当前成功导入，失败保留现有结果。模型展示不将待核对外形视为已经核验；换模型不覆盖照片。管理删除仍走现有预览与确认，不提供整库清空。既有约束见 [当前操作与权限](OPERATIONS_CURRENT.md)。

## 网页与原生契约

网页在当前同源页面发布 `window.__WORKBENCH_MOBILE__`，版本号 `version: 1`。字段包含当前页、账号显示身份、姓名/首字、角色显示名及按既有权限过滤的业务目录；网页另外提供 `pageTitle`。快照不包含密码、登录令牌、厂商 Key、业务正文或分析结果。

原生优先读取此契约，不再依赖门户卡片的 DOM 结构取得完整功能目录；旧门户解析只作为尚未更新服务器的兼容路径。目录是导航依据，不能替代 API 授权。账号或服务器变化时清除会话内常用/最近入口，防止复用其他账号的目录。

网页导航仅接受受支持的站内业务路径；拒绝外站、旧功能、未授权个人中心页签及异常路径。通过 Vue 路由完成切换并检查结果，保留未保存表单的路由守卫；取消离开时不能被原生切换绕过。

## 桌面与小程序边界

手机模式使用 `body.workbench-mobile` 隔离样式。带 `DigitalWorkbenchAndroid/` 标识的本项目 App 始终启用；普通浏览器须同时满足不超过760px和手机用户代理或粗指针设备条件。仅缩窄桌面窗口不会切换为App工作台。Android由原生导航承载顶层入口，避免与手机网页导航重复；`mini=1`始终排除。

桌面保留现有业务导航和表格。`mini=1` 小程序内嵌页不启用本轮手机工作台；小程序源码、登录方式及发布流程不因本轮 App 重做自动变化。

本轮没有新增扫码、推送或离线业务同步。3D、文件、AI 和其他业务仍依赖现有服务器。原生导航与手机专用业务界面不等于所有业务页面已改为 Android 原生控件。

沿用应用 ID `cn.digitalworkbench.mobile` 和既有正式签名。`android.5 → android.6` 通过同签名覆盖升级保留应用私有数据和服务器业务数据。覆盖升级与AES/Keystore跨进程持久性已在本轮最终首页调整前的同签名构建实测，最终APK另重新构建、Lint及校验；未声称完成厂商真机全业务或最终成品完整OTA验收。

正式构建继续使用 `android-app/build-release.ps1`；更新产物通过 `android-app/tools/prepare-update.ps1` 生成独立 APK、更新清单和 SHA256。版本号必须递增，不能用旧版本 APK 文件名替换不同字节。先核对新 APK，再替换服务器更新清单，保留旧安装包和回滚资料。下载安装沿用同站 HTTPS、大小/哈希、包名和签名校验，安装由 Android 系统确认。

正式[手机下载APK](https://czsdsg.cn/app-updates/android/digital-workbench-1.9.10-android.6.apk)、[本地更新清单](../android-app/releases/1.9.10-android.6/latest.json)及[独立校验](../android-app/releases/1.9.10-android.6/SHA256SUMS.txt)已核对。最终APK为58,835字节，SHA256 `d7f06fdbb33f0ea9b9fa402fec6235525a091dd591e80c61936a57485a4f2dab`。手机可从“我的／更多→检查App更新”下载，由系统确认覆盖安装。.5正式APK保留；未发布的.6中间产物已移入Windows回收站。

本轮只更新完整网页成品与独立APK/清单，无API代码、SQL/数据库结构变更或服务重启。回滚目录为 `/opt/spare-parts/rollback/app-rebuild-20261024-141440/`，其中保留`web-dist`及`latest.before.json`；前一有效网页和传输包已移入 `/opt/spare-parts/recycle-bin/app-rebuild-20261024-141440/`，其中有原路径、校验和恢复信息。恢复时先保留当前现场副本；APK清单回退不能强制降低已安装版本。
