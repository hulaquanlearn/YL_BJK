适用本项目 IRB 6700-150/3.20、IRC5 / RobotWare 6.08 离线模型。现场示教器照片用于核对外观；不连接或控制现场机器人。

## 已整改

上线追加：服务器另一实际备份中的 XOR 和多值 CASE 原先导致整库编译失败。现按 [RW6 Kernel表达式及TEST规则](https://library.e.abb.com/public/8f987f25dd9f4ed09f406624444a671e/3HAC050946%20TRM%20RAPID%20Kernel%20RW%206-en.pdf) 支持异或真值表、OR/XOR左结合、AND先于NOT，以及CASE多值首匹配；3项新增回归通过，现存两套备份编译通过。最终 API 50项、网页594项通过，已同步；[部署与验收](ABB_DEPLOYMENT_20261104.md)。

1. 修正轴组键与动作模式键互换；四个可编程键保留未配置，不伪造现场 ProgKeys。启停/单步/停止与当前程序会话联动。
2. 默认无增量；精细/中等/粗增量采用原厂关节与直线步距；线性模式使用基坐标方向、重定位使用法兰/工具方向。连续按住蓝色箭头才重复运动，松开、取消、失焦立即停止。对角方向同时作用于对应轴。
3. 点动和程序动画读取同一个实时速度覆盖值；0% 撤销运动，25/50/100%、±1/±5 调整实际动画时间。MoveL 以工具 TCP 插补，端点与解释器返回关节保持一致。时长为离线估算，不声称复现控制器加速度、转角区与触发时序。
4. 唯一使能按钮：未使能为普通按钮色，已使能为绿色。背部整块 CAD 椭圆使能键及圆角侧壁同步变绿，取消原先画到接缝的狭窄区域。恢复正面视图清除残留轨道阻尼。
5. 摇杆上直接展示八方向与中心停止，移除遮挡示教器的大卡片。按下开始，释放不再产生新步进；程序运行中按箭头不会串入手动运动。
6. 菜单、I/O、备份、文件、程序数据、系统信息、事件、快速设置可操作；放大屏幕与原屏幕共用命中区域，仅保留屏内一个关闭入口。生产窗口/编辑器读取同一备份、例程与当前源码。程序联动面板放在左列。
7. 结构拆解分阶段：工具、线缆、平衡机构连接件、主体、6/5/4/3/2/1 轴；复位反向装回，底座固定。参考/零位两种姿态检查相邻轴真实包围盒间隙，一、二轴大于 0.5 m，其余接口大于 0.15 m。按 CAD 总成粒度演示装配关系，不把省略的螺钉、电机等说成完整维修步骤。
8. 在实际 CAD 按钮护罩处补齐黑色 1–6 编号按钮，护罩使用独立深灰金属材质。选中仍遵循绿色高亮。按钮是部件说明入口，不冒充使能或点动。相邻 SMB 电池仓提供直达手册 187 页的位置图；原展示 CAD 没有电池/板卡内部模型，不捏造内部结构。
9. DSH 修正嵌套分支绝对跳转、无括号过程调用、Incr、tool0 与关节成员引用等解释器问题；Codex 独立复核真实路径及运动端点。

## 仍需区分的边界

- 真实主程序需实际 GI 料位等输入才能验完整上甑流程。当前已验证接料/条件分支，GI 为零时退出不算整段工艺完成。
- StopMove/StartMove、AccSet、配置与触发事件目前部分为标记；TRAP 触发时明确阻断，不执行中断处理体。未实现完整控制器安全链、触发位置时序、实机步退、HotEdit 与校准写入。
- 使能开关是网页离线许可的锁定状态；不声称替代实物三段使能硬件或安全控制器。模拟按钮不产生现场控制命令。
